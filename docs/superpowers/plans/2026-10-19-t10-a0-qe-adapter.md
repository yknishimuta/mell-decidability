# T10-A0-QE Adapter Implementation Plan

**Goal:** Recover the original free-variable Presburger semilinearity theorem without proving that raw MiniCooper elimination preserves a syntactic scope bound.

**Architecture:** Prove that `nat_environment` is zero outside its vector dimension.  On the quantifier-free output of `eliminate`, erase every out-of-range variable summand while retaining ground and abstract constants.  Prove exact semantics under `nat_environment`, obtain `qf_well_scoped d`, and feed the adapted formula to `qf_semicode`.

**Scope:** T10-A0-QE-Adapter only.  Do not implement T10-A or change A0-L/A0-QF.

## Public contract

```coq
presburger_nat_semilinear :
  forall d (cenv : MC.environment) (formula : Syntax.formula),
    Syntax.formula_closed d formula = true ->
    exists code : SemiCode d,
      forall value : NVec d,
        formula_semantics (nat_environment value) formula <->
        denote code value
```

The quantified variables in `formula_semantics` range over `Z`; only the free environment is supplied by `NVec d`.
