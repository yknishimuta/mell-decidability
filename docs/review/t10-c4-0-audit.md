# T10-C4-0 audit: faces of finitely generated rational cones

Baseline: `aa76b88df4d30b6218c8bf073f6ae9ba5c4276dc`.

Scope: C4-0 only.  No face enumeration, face-poset construction, or dimension
decrease result from C4-1 is implemented here.

## Definitions and equality discipline

`theories/Geometry/Faces.v` defines:

- `qinner` by the existing `qrow_apply`/finite rational dot product;
- `SupportingNormal C e` as nonnegativity of `qinner e x` for every `x` in
  `C`;
- `NormalOrthogonal L x` as numerical equality (`Qeq`) to zero for every
  occurrence in the finite list `L`;
- `FaceOf C F` by a finite supporting-normal list `L` and the pointwise
  equivalence `F x <-> C x /\ NormalOrthogonal L x`;
- `face_generators L W` by Boolean filtering with `Qeq_bool`.

The development does not identify `Qeq` with Leibniz equality and proves the
needed `QVecEq` transport lemmas explicitly.  Duplicate generators and
duplicate normals remain distinct list occurrences; the semantics is
insensitive to their repetition.

## Public results

With implicit arguments printed explicitly, the central results are:

```coq
face_generator_filter :
  forall (d : nat) (generators normals : list (QVec d)),
    List.Forall
      (SupportingNormal (qcone_generated generators)) normals ->
    SameSet
      (qcone_generated (face_generators normals generators))
      (fun point =>
        qcone_generated generators point /\
        NormalOrthogonal normals point)

face_self :
  forall (d : nat) (cone : QSet d), FaceOf cone cone

face_subset :
  forall (d : nat) (cone face : QSet d),
    FaceOf cone face -> forall point : QVec d, face point -> cone point

face_contains_zero :
  forall (d : nat) (cone face : QSet d),
    IsCone cone -> FaceOf cone face -> face (qvec_zero d)

face_is_cone :
  forall (d : nat) (cone face : QSet d),
    IsCone cone -> FaceOf cone face -> IsCone face

polyhedral_face_finitely_generated :
  forall (d : nat) (cone face : QSet d),
    RationalPolyhedralCone cone ->
    FaceOf cone face ->
    RationalPolyhedralCone face
```

The `IsCone cone` premise on the zero and cone-closure lemmas is necessary
because `FaceOf` is deliberately defined for an arbitrary ambient `QSet` and
does not silently add a cone premise.

## Filter proof

The forward direction weakens a cone combination over the filtered list to
the original list and proves simultaneous orthogonality by structural
induction on the combination.

For the reverse direction, a combination over `W` whose result is orthogonal
to all supporting normals is inspected constructor by constructor.  For each
normal, both the head contribution and tail contribution are nonnegative.
Their sum is zero, so the tail is orthogonal.  If the head coefficient is
zero, the head is removed by `QVecEq`; otherwise its strict positivity forces
the generator itself to be orthogonal, hence retained by the Boolean filter.
This argument requires neither vector equality decision nor choice.

## Boundary regressions

`theories/Audit/FacesExamples.v` checks:

- dimension zero and the zero cone;
- a signed presentation with lineality and a full-space presentation;
- duplicate, zero, linearly dependent, and redundant interior generators;
- the empty supporting-normal list;
- the two-dimensional nonnegative quadrant with a redundant diagonal
  generator, where filtering by the second-coordinate normal retains exactly
  the first axis;
- the negative example that the diagonal ray is not a face of the quadrant.

The last proof derives that every supporting normal vanishing on `(1,1)`
must vanish on `(1,0)`, which would incorrectly place `(1,0)` in the diagonal
ray.  A separate cone-combination induction refutes that membership.  Thus the
tests establish the intended one-way statement: every exposed face is
generated by a sublist, not every sublist generates a face.

## C4-1 bridge

For a fixed finite generator list `W`, every face has the generator list
`face_generators L W`, which is a sublist of `W`.  Since a finite list has
only finitely many sublists, the C4-0 result supplies a finite candidate cover
for the faces of the cone.  Turning that observation into a face enumeration,
ordering the faces by inclusion, and proving strict dimension decrease remain
explicit C4-1 obligations.
