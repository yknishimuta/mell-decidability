# T10-C4-3B-1-HRep-C audit

## Scope and baseline

- Baseline: `93ae5a10f107ee2ac91ccdd46b098a3cccdbcf55`.
- Scope: extracting a finite rational H-representation of a finitely generated
  cone, homogenizing it, and transporting it to standard `QVec`.
- Integer H-representations, Face-Stripping Lemmas 6.5--6.7, and HRep-D are
  outside this change.

## C0: finite nonhomogeneous base

The installed Coq-Polyhedra interface used by the proof is:

```coq
Polyhedra.polyhedron.is_poly_of_base :
  forall (R : realFieldType) (n : nat) (P : 'poly[R]_n),
    exists base : base_t[R,n], P == polyhedron.poly_of_base base

Polyhedra.polyhedron.in_poly_of_baseP :
  forall (R : realFieldType) (n : nat) (x : 'cV[R]_n)
    (base : base_t[R,n]),
    reflect
      (forall constraint : lrel[R]_n,
        constraint \in base -> x \in mk_hs constraint)
      (x \in polyhedron.poly_of_base base)

Polyhedra.polyhedron.in_hs :
  forall (R : realFieldType) (n : nat),
    (forall (constraint : lrel[R]_n) (x : 'cV[R]_n),
      (x \in mk_hs constraint) =
      (constraint.2 <= '[constraint.1,x])) /\ ...
```

`rat_cone_finite_base` combines these three facts and exposes a finite set of
affine constraints together with a propositional membership equivalence.

## C1: cone closure

```coq
rat_cone_contains_zero : forall d (columns : list ('cV[rat]_d)),
  (0 : 'cV[rat]_d) \in
    polyhedron.cone (rat_fset_of_columns columns)

rat_cone_scale_nonnegative : forall d
    (columns : list ('cV[rat]_d)) (scalar : rat) (value : 'cV[rat]_d),
  is_true (((0 : rat) <= scalar)%R) ->
  value \in polyhedron.cone (rat_fset_of_columns columns) ->
  scalar *: value \in polyhedron.cone (rat_fset_of_columns columns)
```

Both results use the HRep-B list-coefficient characterization. Scaling maps
every coefficient to `scalar * coefficient`, so the proof also covers the
empty generator list.

## C2: homogenization

For every affine constraint in the extracted base,
`rat_cone_constraint_threshold_nonpositive` obtains `threshold <= 0` from
zero membership. `rat_cone_constraint_homogeneous` proves every cone point
satisfies a nonnegative inner product. In the negative case it uses exactly

```coq
scalar := (1 - threshold) / (- '[normal,value])
```

which is positive. Closure under nonnegative scaling puts the scaled point in
the cone, while its affine constraint evaluates to `threshold - 1`, a
contradiction. Conversely, a nonnegative inner product is at least every
nonpositive threshold.

The resulting MathComp theorem is:

```coq
rat_cone_homogeneous_base : forall d
    (columns : list ('cV[rat]_d)),
  exists normals : list ('cV[rat]_d),
    forall value : 'cV[rat]_d,
      value \in polyhedron.cone (rat_fset_of_columns columns) <->
      forall normal : 'cV[rat]_d,
        List.In normal normals ->
        is_true (((0 : rat) <= '[normal,value])%R)
```

No pointedness, full-dimensionality, or rank hypothesis is used.

## C3: standard-Q transport

`rat_col_qinner` identifies the standard inner product, after `q_to_rat`,
with Coq-Polyhedra's `vdot`. It uses `q_to_rat_qinner`,
`qvec_to_rat_row_transpose`, and `rat_col_to_qvec_roundtrip`.
`rat_col_qinner_nonnegative_iff` then uses
`q_to_rat_nonnegative_iff` to reflect the order proposition.

The final public theorem is:

```coq
polyhedra_cone_homogeneous_base : forall d
    (generators : list (QVec d)),
  exists normals : list (QVec d),
    forall value : QVec d,
      qcone_generated generators value <->
      forall normal : QVec d,
        List.In normal normals -> Qle 0 (qinner normal value)
```

The proof maps the rational normals through `rat_col_to_qvec` and uses
`qcone_generated_polyhedra_cone`. Standard rationals remain related by
numeric equality and order; no Leibniz equality of nonnormalized `Q` values
or functional extensionality is used.

## Regression coverage

The focused examples cover dimension zero, the empty generator list, the
zero cone, positive and negative rays, a full line (lineality), the
two-dimensional nonnegative orthant, duplicate and redundant generators,
and numerically equal nonnormalized generators. A direct coefficient proof
shows that the rank-one ray generated by `(1,0)` excludes `(0,1)`; the final
H-representation is then shown to exclude that same point. Zero containment
and arbitrary nonnegative rational scaling are checked independently.

The threshold regressions augment an extracted finite base with a redundant
zero-normal constraint, once at `threshold = -1` and once at `threshold = 0`,
and invoke `rat_cone_constraint_homogeneous` on that actual augmented base.

## Verification and assumptions

The final verification runs:

```text
make OPAMEXEC= check-t10-c4-3b-1-hrep-c
make OPAMEXEC= audit-t10-c4-3b-1-hrep-c
make -f Makefile.coq -j2
git diff --check -- <the five HRep-C target files>
```

The focused audit invokes `coqchk -silent` for
`Mell.Geometry.QratHomogeneousAdapter` and
`Mell.Audit.QratHomogeneousAdapterExamples`. `Print Assumptions` is run for
nine public proof results. Source gates reject `Admitted`, `Abort`, new
`Axiom`, `Classical_Prop.classic`, `ClassicalEpsilon`, UIP/K,
`Eq_rect_eq`, functional extensionality, constructive indefinite
description, and external oracles.

## HRep-D boundary

HRep-D still owns clearing denominators in the finite standard-Q normal list,
constructing integer normals, and proving that this preserves all
inequalities. No integer H-representation or Face-Stripping result is added
here.
