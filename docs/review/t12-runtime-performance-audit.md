# Task 12 runtime performance audit

Date: 2026-10-26

## Environment

- Coq 8.20.1, compiled with OCaml 4.14.2
- OCaml 4.14.2 native runner (`ocamlopt`)
- Zarith 1.14 / GMP arbitrary-precision integers
- macOS, no explicit memory limit
- baseline and final comparisons use a 60-second wall-time ceiling

## P0: stage separation

The original extracted path was measured separately at reduction generation
and certificate search.

For `[One]`, the runtime compiler generated a full-zero system with 4
subformulas, 1 support, 30 unary rules, 64 split rules, and no zero-test
rules.  The generic zero-test elimination nevertheless constructed 254
syntactic states, 64,516 layered states, and 23,876 layered rules; the erased
IBVAS dimension was approximately 89,408.  Reduction alone did not terminate
within 60 seconds.

After the zero-test-free direct conversion, reduction of `[One]` completed in
0.20 seconds (0.18 seconds user CPU) and produced an IBVAS of dimension 352,
with 1 initial vector and 188 actions.  The empty sequent produced dimension
10, 1 initial vector, and 4 actions.  Thus the original reduction blow-up was
caused by unconditional layering.

Once reduction completed, `mell_decide [One]` still timed out at 60 seconds.
Fuel 10 and fuel 100 both returned `None`; direct stateful saturation found
the root in round 5 among 423 configurations in 0.49 seconds.  This isolates
the second bottleneck: sequential enumeration of large Gödel codes for proof
trees, rather than certificate checking itself.  `reduce_mell` is passed once
to the fallback search; it is not rebuilt at each fallback stage.

## P1: zero-test-free direct conversion

`Reduction/ZeroTestFree.v` defines a direct bottom-up SBVAS conversion and a
decidable zero-test-free guard.  Its principal theorem is:

```coq
direct_zero_test_free_correct :
  forall d State eq_dec (system : FullZeroBVASS d State) state counters,
    zero_test_freeb system = true ->
    In state (full_zero_states system) ->
    FullZeroReach system state counters <->
    SReach (direct_bottom_up eq_dec system)
      (direct_root_state eq_dec system state) counters
```

The public `reduce_mell` tests the full-zero rule list before constructing any
layered system.  A zero-test-free input uses the direct conversion; inputs
with tests retain the original verified layering.  The public correspondence
to the reference reduction is:

```coq
reduce_mell_optimized_correct_reference :
  forall Gamma,
    Holds (reduce_mell Gamma) <-> Holds (reduce_mell_reference Gamma)
```

Both the direct-conversion theorem and the correspondence theorem are closed
under the global context.

## P2 decision

Exact root-reachability pruning was not installed in the public reduction.
P1 made reduction generation sub-second, while the remaining timeout occurred
after reduction in proof-code enumeration.  Post-generation pruning would
therefore not address the measured principal cause.  No unproved state or
rule deletion is performed.

## P3: verified prechecks and fallback

`Logic/UnitFragment.v` recognizes singleton formulas generated by `One`,
`Tensor`, and `Bang`.  Its soundness theorem constructs the corresponding
cut-free `Derivation` recursively, including promotion for `Bang`; rejected
formulas fall through.  This removes the extracted stack overflow previously
observed for `[Bang One]` without special-casing that concrete input.

`BVASS/FiniteSaturation.v` provides finite stateful saturation.  A positive
answer is an `SReach` proof; a negative answer is emitted only after an exact
list fixed point, and is proved to exclude every `SReach` derivation.

For larger systems a bounded backwards slice from the queried root is used
only as a YES precheck.  `slice_sreach_sound` transports every sliced
derivation to the original system.  Negative sliced answers are discarded,
so insufficient slice depth cannot produce NO.

The fast path tries depth 6 and then depth 9.  The tensor-unit example reaches
the root at depth 9 (604 configurations).  Small full systems additionally
use fixed-point saturation for both YES and NO.  If neither precheck decides,
the original fair certificate/invariant search is used unchanged.

For the multiplicative fragment, `Logic/MultiplicativeWeight.v` proves that
every cut-free derivation without exponentials has sequent weight 1.  A
different weight is therefore a general sound NO certificate.  It decides
`[One; One]` without an input-specific branch; exponential sequents are left
undecided and fall through.

All new precheck soundness theorems are closed under the global context.  The
existing total fallback, eventual-success theorem, and fair alternation of
run and invariant certificates remain the completeness argument.
