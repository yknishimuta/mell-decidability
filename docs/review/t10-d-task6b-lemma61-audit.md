# T10-D Task 6B audit: Leroux Lemma 6.1

## Scope and correspondence

This checkpoint formalizes the decomposition in Leroux (2012), Lemma 6.1,
for a stateless VAS and one linear relation `r + P`.  It does not formalize
Lemma 6.2, almost semilinearity, Corollary 6.3, or the finite-control lift.

`LinearReachRestricted system data source target` is exactly the conjunction
of VAS reachability and membership of the endpoint pair in the linear
relation.  `linear_reach_restricted_iff_omega_run` relates it to an actual
valid run in `LinearOmegaRun`; endpoint membership alone is never used as a
reachability witness.

For a run `rho`, `LinearRunTransformerComponent` is exactly

```text
dir(rho) + (TransformerAlongRun rho intersect GeneratedPeriodPair P).
```

It existentially quantifies one input/output offset pair, requires both
transformer membership and membership in the same generated periodic
relation, and adds the two offsets to the corresponding endpoints of `rho`.
The two offsets need not be equal.

## Both inclusions

`linear_run_transformer_component_sound` proves the component-to-restricted
reach direction.  It uses `transformer_realized_by_jancar_extension` to obtain
an actual valid extension run with the stated endpoints.  The original
Omega-run and the generated period increment are then combined through
`linear_omega_run_upward`; reachability and linear membership therefore have
separate witnesses before they are conjoined.

`linear_finite_cover_component_complete` proves the reverse direction for a
fixed sound and covering basis.  From a restricted reach pair it extracts an
Omega-run, obtains a covering basis run using `LinearRunLe`, and applies
`linear_run_le_transformer_period_witness`.  The latter supplies the same
offset pair as both a transformer witness and a generated-period witness.

`linear_reach_finite_basis_decomposition` packages these two inclusions as a
pointwise relation equivalence.  No functional extensionality is used.

`lemma_6_1_linear_reach_decomposition` instantiates the fixed-basis theorem
with the finite basis from `linear_omega_finite_cover`.  Its conclusion is

```text
Reach intersect (r + P)
  = union over rho in basis of
      dir(rho) + (TransformerAlongRun rho intersect P)
```

where equality is pointwise `iff`.

The paper indexes its union by literal minimal runs.  The Coq theorem indexes
the same decomposition by the already-proved finite covering basis.  The
decomposed relation is identical, but this checkpoint does not claim that the
chosen basis is literally the set of all minimal runs or that `LinearRunLe`
is antisymmetric.

## Periodicity handoff

`linear_transformer_period_intersection_periodic` proves that the offset
relation used inside every component is periodic.  It combines
`transformer_along_run_periodic` with `generated_period_pair_periodic`.

Task 6C still needs the following mathematical adapters/results (names are
proposals, not assumptions introduced here):

```coq
periodic_nrelation_intersection_asymptotic :
  AsymptoticallyDefinableNRelation R ->
  AsymptoticallyDefinableNRelation P ->
  AsymptoticallyDefinableNRelation
    (fun input output => R input output /\ P input output).

generated_period_pair_asymptotically_definable :
  forall generators,
    AsymptoticallyDefinableNRelation
      (GeneratedPeriodPair generators).

linear_run_transformer_component_almost_semilinear :
  forall system data rho,
    AlmostSemilinearNRelation
      (LinearRunTransformerComponent system data rho).
```

The key unresolved proof obligation is the appropriate cone/intersection
connection plus `QDefinable` intersection for the encoded relation.  This
checkpoint proves only periodicity and makes no Lemma 6.2 or almost
semilinearity claim.

## Regression coverage

The focused audit covers dimension zero, an empty Omega with the exact empty
basis, an empty-action system, length-zero runs, empty generators, nonzero
base endpoints, unequal input/output offsets, and the identity component
generated by `(1,1)`.  Two explicit negative regressions separate the two
essential component conditions:

- a real transformer offset `(0,1)` is rejected when the generated period is
  empty;
- a generated period offset `(0,1)` is rejected when the empty VAS cannot
  realize it.

Task 6A regressions continue to cover zero and duplicate generators, duplicate
actions, multiple-action runs, non-unique coefficient representations,
Jančar-without-period, period-without-Jančar, and both conditions together.
